# MD→문서 변환기

강의 영상 요약 프로그램이 만든 분석 결과 마크다운(`.md`)을 읽기 좋은 **Word(.docx)** 또는 **PDF** 문서로 한꺼번에 바꾸는 Windows 프로그램입니다. 설치 없이 exe 하나로 실행됩니다.

## 1. 바로 쓰기 (exe)

1. `MD→문서 변환기.exe`를 원하는 폴더에 두고 더블클릭합니다. Python은 필요 없습니다.
2. **[파일 추가]**로 `.md` 파일을 고르거나, md 파일·폴더를 창에 끌어다 놓습니다. 폴더를 놓으면 안의 md를 모두 찾습니다.
3. 출력 폴더를 고르거나 **「원본 md와 같은 폴더에 저장」**을 체크합니다.
4. 형식(**DOCX / PDF**)을 고르고 **[변환 시작]**을 누릅니다.
5. 끝나면 **[출력 폴더 열기]**로 결과를 엽니다. 실패한 파일은 상태 칸에 마우스를 올리면 이유가 보입니다.

- 출력 파일 이름은 md 이름과 같고 확장자만 바뀝니다 (`강의_정리.md` → `강의_정리.docx`).
- 같은 이름의 파일이 있으면 「덮어쓰기 / 건너뛰기 / 모두 덮어쓰기」를 묻습니다.
- 마지막 설정은 `%APPDATA%\MD문서변환기\settings.json`에 저장됩니다.

### PDF 변환 엔진

창 아래 상태 표시줄에 「PDF 변환 엔진: Word / LibreOffice / 없음」이 나옵니다.

| 엔진 | 동작 |
|---|---|
| **Word** (권장) | 차례의 쪽 번호를 실제 위치로 갱신하고, PDF에 제목 책갈피와 차례 링크를 넣습니다. 사용자가 열어 둔 Word 창은 건드리지 않습니다. |
| LibreOffice | PDF를 두 번 만들어 쪽 번호를 맞춥니다. |
| 없음 | DOCX만 만들 수 있습니다. Word에서 열 때 쪽 번호를 갱신할지 물으면 「예」를 누르세요. |

## 2. 만들어지는 문서

- **1쪽 표지**: 제목, 제공 기관·강사·강의 시간·구성·원본 영상 표
- **2쪽 차례**: Ctrl + 클릭하면 해당 제목으로 이동하고, 쪽 번호가 표시됩니다
- **본문**: 제목 계층, 표(본문 폭 꽉 채움, 머리글 행 반복), 콜아웃 상자, Word 번호 매기기, 클릭되는 체크박스(`- [ ]`), 수식(`$...$`, `$$...$$`), 이미지
- **부록. 문서 정보**: `inputs`, `numeric_policy`, `slip_policy` 같은 파이프라인용 정보

변환 옵션:
- **수치 자동 강조**: `40~50초`, `100만 원`, `85%`처럼 숫자와 단위가 붙은 표현을 굵게 표시합니다.
- **특정 절 자동 상자화**: 「강의자가 강조·반복한 내용」은 📌 상자로, 「원본 확인이 필요한 부분」은 ⚠️ 주의 상자로 만듭니다.

이 프로그램은 서식만 바꿉니다. 내용을 요약하거나 문장을 고치지 않습니다.

## 3. 직접 빌드하기 (개발자용)

C/C++의 「컴파일러 + 빌드 스크립트」에 해당하는 것이 「Python + build.bat」입니다.

### 준비 (한 번만)

1. Python 3.11을 설치합니다 (<https://www.python.org/downloads/> → Windows installer 64-bit). 설치 화면에서 **「Add python.exe to PATH」**를 체크합니다.
2. 명령 프롬프트에서 `py -3.11 --version`이 `Python 3.11.x`를 출력하는지 확인합니다.

### 빌드

이 폴더에서 `build.bat`를 더블클릭하거나 명령 프롬프트에서 실행합니다.

```bat
build.bat          :: 가상환경 생성 → 라이브러리 설치 → 테스트 → exe 빌드
build.bat notest   :: 테스트 건너뛰기
```

결과물은 `dist\MD→문서 변환기.exe` 하나입니다.

- `.venv` 폴더는 이 프로젝트 전용 Python 환경(가상환경)입니다. 지워도 `build.bat`를 다시 실행하면 새로 만들어집니다.
- 처음 빌드는 라이브러리 내려받기 때문에 몇 분 걸립니다.

### 빌드 없이 실행·테스트

```bat
.venv\Scripts\python app.py                     :: GUI 실행
.venv\Scripts\python app.py --convert a.md b.md --format pdf --out 출력폴더
.venv\Scripts\python -m pytest -q tests         :: 테스트
.venv\Scripts\python tests\verify_word.py 폴더  :: Word로 배치 검사(차례 쪽, 쪽 번호, 제목 고립, 빈 공간)
```

`--convert`는 창 없이 변환하는 명령줄 모드입니다. exe에서도 같은 인수를 쓸 수 있고, `--log 파일`을 주면 결과를 파일로 남깁니다.

## 4. 서식 바꾸기

색, 글꼴, 크기, 줄 간격, 단락 간격, 상자 색은 모두 **`styles.py`** 한 곳에 있습니다. 값을 고친 뒤 `build.bat`를 다시 실행하면 됩니다.

## 5. 폴더 구조

```
app.py            GUI 진입점 (+ --convert 명령줄 모드)
worker.py         변환 작업 (QThread)
md_parser.py      md → 중간 모델(블록 목록)
docx_builder.py   중간 모델 → docx (표지·차례·본문·서식 규칙)
styles.py         색·글꼴·간격 상수
ooxml_helpers.py  OOXML 직접 작성 (스키마 순서, 책갈피, 필드, 체크박스, 표 테두리)
pdf_export.py     Word COM / LibreOffice / 쪽 번호 갱신
settings.py       설정 저장
md2doc.spec       PyInstaller 설정
build.bat         빌드 스크립트
make_icon.py      app.ico 생성 (개발용)
tests/            테스트와 샘플 md
```

## 6. 알아 둘 점

- **PDF의 이모지는 흑백입니다.** Word의 PDF 내보내기가 컬러 이모지를 지원하지 않기 때문입니다. 그래서 PDF용으로는 흑백 이모지 글꼴(Segoe UI Symbol)을 써서 파일 크기를 수 MB 줄입니다. DOCX에서는 컬러 이모지(Segoe UI Emoji)로 보입니다.
- **수식**은 Word에 포함된 `MML2OMML.XSL`로 Word 수식으로 바꿉니다. Word가 없으면 기울임 글씨로 넣습니다.
- **이미지와 수식이 있는 단락**은 그림이 잘리지 않도록 줄 간격을 「고정」 대신 「최소」로 둡니다.
- **자동 상자화 절 안의 표**는 상자에 넣지 않고 독립된 표로 두며, 머리글 행을 상자 색으로 칠합니다. 큰 표를 상자(단일 셀 표) 안에 넣으면 Word가 그 행을 쪽에서 나누지 못해 상자가 통째로 다음 쪽으로 밀리기 때문입니다.
- **LibreOffice 경로**는 이 PC에 LibreOffice가 없어 실제로는 검증하지 못했습니다.
